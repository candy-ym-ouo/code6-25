# 木偶剧团巡演

## 启动

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。API 默认运行在 `http://localhost:3001`，存档写入项目根目录的 `data.json`。生产构建使用 `npm run build`，规则冒烟测试使用 `npm test`。

## 已实现闭环

创建剧团 -> 选择路线 -> 调查小镇传说 -> 选择剧目 -> 编排动作 -> 分配结尾 -> 后端校验 -> 演出快照与确定性结算 -> 资金/声望/演员成长 -> 下一站 -> 终局。

所有结算由 API 执行，演出结果写入持久化 JSON 存档；重复刷新不会丢失当前进度。

存档每次写入携带持久化代次（generation）与 SHA-256 校验和，并以「tmp 写入 + 原子替换」落盘，成功响应即代表已持久化，立即重启不丢进度。上一完整版本保留在 `data.json.bak`：主存档损坏或校验失败时自动从备份恢复，无法恢复的损坏文件会隔离为 `*.corrupt-*` 留待人工处理，不会静默丢档。
